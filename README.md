## About the Initiative
**Cosmos, Nowness, Eternities (CNE / CINI)** is a non-profit, non-ownership civic initiative and Open Civic Commons dedicated to rebooting scientific knowledge, advancing human identity through cosmic humility, and encoding non-relational compassion across Deep Time. 

Anchored in relational time, scientific instrumentation outreach, historical hindsight, and structural mercy toward sentient co-travelers, all records in this repository are archived permanently on Zenodo under CC-BY-4.0.
